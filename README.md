# TFM

## Reconstructing ancestral gene regulatory toolkits through comparative genomics of unicellular Holozoa

Understanding the origin of complex multicellularity in animals remains a central challenge in evolutionary biology. Developmental transcription factors (DTFs) play essential roles in cell differentiation and body-plan patterning in Metazoa. Although many DTFs were once considered animal-specific, recent studies on unicellular Holozoa, the closest living relatives of animals, have revealed that several homeobox families emerged earlier than previously assumed. In this study, we investigate the evolutionary history and expression patterns of non-TALE homeobox genes across representative unicellular holozoan lineages. We developed a customised bioinformatic pipeline integrating HMMER and BLAST searches to detect candidate homeodomain-containing sequences. The evolutionary history of these candidates were validated using Maximum Likelihood phylogenies. Our results indicate that non-TALE homeobox genes are more diverse and widely distributed among unicellular Holozoa than previously recognised, suggesting an unexpectedly deep evolutionary origin for key developmental regulators. These findings provide new insights into the genomic toolkit that predate animal multicellularity and underscore the early emergence of transcriptional complexity in holozoan evolution.

In this repository you will find:

+ The full thesis in a pdf format (TFM.pdf).

+ A directory with the phylogenetic trees in a treefile format, the R script to analyze them and a csv file to correctly configure the names of the sequences. If you download the full directory and run the script it should work directly.

+ The final dataset, product of running the R script with does phylogenetic trees.
